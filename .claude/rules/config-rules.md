# Configuration Rules (PART 5, 6, 12)

⚠️ **These rules are NON-NEGOTIABLE. Violations are bugs.** ⚠️

## CRITICAL - NEVER DO
- Do not add web administration or account configuration.
- Do not silently ignore invalid configuration.

## CRITICAL - ALWAYS DO
- Keep server configuration in server.yml and document defaults.
- Validate configuration before starting services.
