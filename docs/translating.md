# Translating

The Quotes interface and documentation currently ship in English. There is no translation catalog or translated UI yet. When adding a language, keep the browser pages, server messages, CLI output, and documentation consistent.

## Translation workflow

1. Discuss the target language and terminology before adding strings.
2. Keep source strings in the project’s established translation format and preserve stable message keys.
3. Translate user-visible text, including validation and error messages, navigation labels, accessibility labels, and CLI help.
4. Keep placeholders, route names, command names, code, and API field names unchanged.
5. Have a fluent reviewer check meaning, terminology, and accessibility before release.
6. Update this guide and the README when translation support ships.

Do not translate quote records or attribute translations to original authors unless the source and translation rights are documented.
