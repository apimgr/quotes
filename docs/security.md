# Security

Quotes is a public, read-only quote service with no user accounts or community quote submissions. MCP requires an owner-linked Bearer token; public quote reads remain unauthenticated. Anonymous owners have no profile, password, or login. Their primary token can manage revocable linked tokens, and API routes accept Bearer credentials rather than browser cookies. Contact reports are validated, rate-limited, encrypted at rest, and handled separately from the quote catalog. Incoming query parameters are validated, request paths and bodies are bounded, and lists are paginated. CORS is open for public quote data.

The rate limiter, report spam controls, and GeoIP filter share a normalized client address. Forwarding headers are accepted only when the TCP peer matches `server.trusted_proxies.additional`; otherwise every forwarded value is ignored. Configure trusted proxy CIDRs only for proxies that overwrite the selected header. Responses include content-type sniffing, framing, referrer, content-security, and permissions policy headers. `/server/healthz` negotiates HTML, plain text, or JSON using `Accept`; `/api/v1/server/healthz` and `/api/healthz` return JSON. `/.well-known/security.txt` and `/security.txt` publish the project security contact route.

Quote records are embedded in the executable. Only include material with documented redistribution rights and retain source attribution and license information. The current sample data is illustrative and must not be presented as an authoritative or licensed corpus.


The operator Bearer token is generated into `secrets.yml` with mode `0600`; keep it private and never place it in browser storage, pages, or logs. Metrics bearer secrets are separate per-service tokens in the same protected file. Browser preference writes use a `csrf_token` double-submit cookie and require the same token in the form. Preference values are limited to the supported theme and language enums; sync imports are additive and ignore unsupported fields. The preference API only writes browser preference cookies; protected API routes do not use browser cookie credentials.
